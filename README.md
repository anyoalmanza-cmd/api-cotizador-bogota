# Bogota Real Estate Machine Learning Pipeline

Proyecto modular con arquitectura limpia para estimación de precios inmobiliarios en Bogotá mediante un ensamble Deep Learning (PyTorch) y servido con FastAPI.

## Comandos Rápidos
1. Instalar requerimientos: `pip install -r requirements.txt`
2. Entrenar modelos: `make train`
3. Correr tests unitarios: `make test`
4. Lanzar servidor API: `make run`
